# Hello World Composite Action

A composite GitHub Action that greets a person, generates a random number, and runs `goodbye.sh`.

## Inputs

| Name | Description | Required | Default |
|---|---|---|---|
| `who-to-greet` | Who to greet | Yes | `World` |

## Outputs

| Name | Description |
|---|---|
| `random-number` | A random integer generated by Bash |

## Usage

```yaml
steps:
  - uses: ./my-custom-action-composite
    with:
      who-to-greet: 'Mona the Octocat'
```

The repository includes a push workflow at `.github/workflows/test.yaml` that exercises the action and exposes its `random-number` output.
